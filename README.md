# 🫀 CPR 상황극 교육 프로그램

실전 상황을 통한 심폐소생술 교육 프로그램입니다. 시나리오 기반 역할극과 체크리스트를 통해 CPR 절차를 효과적으로 학습할 수 있습니다.

## 📋 프로그램 구성

### 1. 메인 프로그램 (`index.html`)
- **상황극 진행**: 조별로 나누어 CPR 상황극을 진행
- **역할 배정**: 학생별로 역할을 랜덤 배정
- **타이머**: 제한시간 내 상황극 진행
- **점수 입력**: CPR 수행 점수 기록
- **결과 분석**: 전체 교육 결과 통계 및 내보내기

### 2. 학습 프로그램 (`study/index.html`)
- **개별 학습**: 시나리오와 역할별 개별 학습
- **체크리스트**: 역할별 수행해야 할 작업 목록
- **상세 가이드**: 각 단계별 상세 설명
- **환경음**: 상황별 배경음악으로 현실감 증대

## 🚀 주요 기능

### 교육 설정
- 총 조 수 설정 (1-10조)
- 상황극 제한시간 설정 (3-10분)
- 학생 명렬 파일 업로드 (Excel, CSV 지원)
- 조별 인원 설정 (3-6명)

### 시나리오
1. **거리에서** - 도로변 심정지 환자 발견
2. **교실에서** - 실내 심정지 환자 발견
3. **체육관에서** - 운동 중 심정지 환자 발견
4. **상가에서** - 쇼핑 중 심정지 환자 발견
5. **운동장에서** - 야외 심정지 환자 발견
6. **식당에서** - 식사 중 심정지 환자 발견
7. **구급차에서** - 이동 중 심정지 환자 발견

### 역할 체계
- **3명**: 초기발견자(통합), 신고자(통합), 보조자(통합)
- **4명**: 초기발견자1, 초기발견자2, 신고자/보조자1(통합), 신고자/보조자2(통합)
- **5명**: 초기발견자1, 초기발견자2, 보조자1, 신고자1, 신고자2/보조자2(통합)
- **6명**: 초기발견자1, 초기발견자2, 신고자1, 신고자2, 보조자1, 보조자2

### 체크리스트 항목
각 역할별로 수행해야 할 작업들이 체크리스트로 제공됩니다:
- 환자 의식 확인
- 119 신고 및 장소/상태 설명
- AED 요청 및 사용
- CPR 시작 및 이어받기
- 주변 안전 확보

## 💻 사용 방법

### 1. 메인 프로그램 실행
```bash
# 웹 브라우저에서 index.html 파일 열기
open index.html
```

### 2. 교육 설정
1. 총 조 수와 제한시간 설정
2. 학생 명렬 파일 업로드 (선택사항)
3. 조별 인원 설정
4. "교육 시작" 버튼 클릭

### 3. 상황극 진행
1. 각 조별로 역할 배정
2. 시나리오 선택 및 상황극 시작
3. 제한시간 내 역할 수행
4. CPR 점수 입력
5. 다음 조로 진행

### 4. 학습 프로그램 사용
```bash
# study 폴더의 index.html 파일 열기
open study/index.html
```
1. 학습할 시나리오 선택
2. 학습할 역할 선택
3. 체크리스트 항목 클릭하여 상세 가이드 확인

## 🎯 교육 효과

1. **실전감각**: 현실적인 시나리오와 환경음으로 실제 상황 연출
2. **역할 이해**: 각자의 역할과 책임을 명확히 인식
3. **절차 숙달**: 체크리스트를 통한 체계적인 CPR 절차 학습
4. **팀워크**: 조별 협력을 통한 응급상황 대처 능력 향상
5. **시간 관리**: 제한시간 내 효율적인 의사결정 훈련
